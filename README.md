# Valve Proton Binaries
What's This?
------------
In this repository are unofficial binary builds of Proton; made using Github Actions and Docker.

Unpack then run `STEAM_COMPAT_CLIENT_INSTALL_PATH=proton-prefix STEAM_COMPAT_DATA_PATH=proton-prefix path/to/proton-version/proton run explorer` to use.

Proton is a compatibility layer that lets Linux users play Windows games. If you use the Steam client then you already have Proton. I don't use the Steam client.

See [here](https://github.com/ValveSoftware/Proton) for details. Also see [GloriousEggroll's Proton](https://github.com/GloriousEggroll/proton-ge-custom).
